# Data Analytics Internship - Task 3: Data Visualization

## 📌 Project Overview
This project is part of the CodeAlpha Data Analytics Internship. The objective is to transform raw data into advanced visual formats, graphs, and dashboards to uncover patterns and support decision-making.

## 🛠️ Tools & Libraries Used
* **Programming Language:** Python 3.x
* **Environment:** Google Colab / Jupyter Notebook
* **Libraries:** 
  * `pandas` - Data manipulation
  * `matplotlib` & `seaborn` - Advanced statistical plotting and dashboard creation

## 📊 Visualizations & Insights
* **Price Distribution Histogram:** Visualized the frequency and density of book prices using KDE curves.
* **Cumulative Distribution Function (ECDF):** Mapped the cumulative probability distribution to analyze pricing tiers across the dataset.
